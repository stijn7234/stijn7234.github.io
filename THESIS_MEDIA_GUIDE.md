# Thesis media naming

## Images
Place these files in `assets/images/`:

- `thesis-device.jpg` — main hero photo of the complete hand trainer
- `thesis-demo-poster.jpg` — still image shown before the demo video plays
- `thesis-pipeline.png` — tracking pipeline diagram
- `thesis-optitrack.jpg` — photo of the OptiTrack validation setup
- `thesis-accuracy.png` — OPTIONAL planar accuracy plot

## Video
Place this file in `assets/videos/`:

- `thesis-demo.mp4`

Recommended video: MP4/H.264, 720p or 1080p, preferably 10–30 seconds, no audio needed.

If you use these exact names, you do not need to edit `projects/thesis.html`.
